About AdSkipper by Wiltfield

What it does

A browser extension for YouTube that mutes ads and clicks the Skip button as soon as it shows up. No more reaching for the mouse, and no more ad noise at night.

  • Mutes the video as soon as an ad starts playing
  • Clicks the Skip button the moment it appears
  • Small popup with a light/dark theme toggle and a Donate button

Install

AdSkipper is not on the browser stores yet, so you add it manually. It takes about a minute.

1. Download

  1. On the GitHub repo page, click Code > Download ZIP.
  2. Extract the ZIP anywhere you like (keep the folder; the browser reads it from there).
  3. Inside the extracted repo, find the folder named AdSkipper by Wiltfield. This is the extension folder, and it contains manifest.json.

2. Add it to your browser

Chrome, Brave, Edge and other Chromium browsers

  1. Open the extensions page: chrome://extensions (Chrome), brave://extensions (Brave) or edge://extensions (Edge).
  2. Turn on Developer mode (top right or bottom left, depending on the browser).
  3. Click Load unpacked and select the AdSkipper by Wiltfield folder.
  4. Pin the extension from the puzzle-piece menu if you want quick access to the popup.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on.
  3. Select the manifest.json file inside the AdSkipper by Wiltfield folder.

Firefox removes temporary add-ons when the browser closes, so you need to repeat these steps after each restart.

Updating

Download the ZIP again, replace your old folder with the new one, then click the reload icon on the extension's card in your browser's extensions page.
